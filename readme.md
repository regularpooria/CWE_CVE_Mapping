# CWE to CVE Mapping Project

## How to get setup

### Environment (Linux, WSL)

- 1. You can use python's "virtualenv" tool to create an environment, here's how that goes:

````pip install virtualenv
virtualenv ./venv
source venv/bin/activate```

- 2. You can use conda if you prefer (this is what i prefer):
```conda create -p ./venv python=3.12
conda activate ./venv
```
